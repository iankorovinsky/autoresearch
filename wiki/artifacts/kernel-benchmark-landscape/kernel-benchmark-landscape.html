How to read “open source”

Yes — open license: released task assets/generators have a standard open code/data license or explicit project declaration. Repository-level licensing is not a legal audit of every imported asset. Public — restricted/custom: public access with special terms. Public — license unverified: assets visible, but reuse rights not established. Partial: only part of the package verified/obtainable. No: private, commercial or explicitly unreleased. Unverified: release not established.

Data includes prompts, reference code, shapes, generators and tests. It need not be a static dataset file. Public tests may still be hidden from the model during an evaluation. Hardware access and external model weights are separate.

Interpretation and important distinctions

KernelBench derivatives, production suites and hardware ports overlap; their task counts cannot be added into a unique-problem total. Speedup depends on baseline implementation, device, precision, shapes, compilation treatment and agent budget. This catalog does not rank model scores.

ComputeEval and SOL-ExecBench data have NVIDIA evaluation-only terms even though their harnesses are Apache-2.0. GPU MODE competition assets and KernelBook currently apply reciprocity conditions to model-improvement use.

THUNLP's TritonBench is a generation benchmark; Meta/PyTorch's tritonbench is an operator-performance suite. Infatoshi's KernelBench-v3 is a community project, not Stanford KernelBench's official version number. Training corpora, validator studies and traditional performance suites are grouped separately from direct generation evaluations.

Search method and limits

Searched papers, project sites, model system cards, GitHub and Hugging Face using kernel-generation, kernel-optimization, CUDA, Triton, Pallas, NKI, Ascend, MUSA, Metal, scientific/HPC, translation and validation terms. Followed citations and catalogs, then inspected author/project sources, release descriptions and available license files. Code licenses were checked separately from external dataset terms where possible.

This is a manual evidence audit as of 2026-11-21, not a registered systematic review. No benchmark was executed. Some OpenReview pages were blocked; some repositories and datasets were inaccessible; some licenses could not be retrieved. These limits are recorded rather than treated as evidence that no public release exists. Current repository counts are preferred when explicit; older paper counts can differ.
